# RCNN
纯手动实现RCNN

训练

1.  输入一张图片，预生成5个尺寸的锚框，那么每像素都生成5个不同尺寸的锚框
2.  为这些锚框分配与其最大的iou的真实框，如果小于iou阈值，就为背景
3.  计算每个锚框与其分配到的真实框的偏移量
4.  将剩下的锚框圈中的像素，强制拉到224*224，
5.   在ImageNet（1000类）上训练好的AlexNet，最后一层（1000类分类）换成 (N+1)类，生成的锚框（IoU>0.5为正样本）去微调，微调完成后，这个CNN才被固定下来，参数冻结
6.  每次将一个锚框框住的像素图导入fine_tuning之后的cnn网络中，提取最后一层输出的4096维的特征向量
7.  将4096维的向量分别导入n类个2分类的svm中，每一个svm都会算出一个置信度分数，选择最高的那个当作类别
8.  将4096维的向量导入线性模型中，输出偏移量
9.  训练svm和线性模型

推理：

1.	提取锚框，缩放至224x224，过冻结的AlexNet，得到4096维向量
2.	将4096维向量同时点乘20个SVM的权重，得到20个分数。如果最高分低于某个阈值，则判定为背景。
3.	对判定为有物体的框，将4096维向量输入线性回归模型，得到预测的偏移量，对锚框位置进行微调（精修）。
4.	最后执行非极大值抑制（NMS），去掉重复的框。
